# مخطط إعادة تنظيم إعدادات Horizons-DE

تم تنفيذ التنظيم الأساسي وتحسين الواجهة — 8 سبتمبر 2026. مبني على صفحات الإعدادات في نسخة العمل الحالية، بما فيها تعديل استقلال ويدجتس شاشة القفل عن الديسكتوب.

التنظيم المعتمد: تقسيم القائمة إلى **«التخصيص العادي» ظاهر مباشرة** و**«متقدم» مغلق بسهم**. فتح السهم يُظهر جميع فروع الإعدادات المتقدمة، بما فيها المحررات والتفاصيل التقنية؛ اختيار الفرع يفتح محتواه. يبقى لكل خيار مكان واحد، وتُستخدم روابط الوصول السريع للوصول إليه من السياقات الأخرى.

## 1. نطاق المراجعة وما يسبب التشتت

شملت المراجعة صفحات Quick وGeneral وBar وDesktop وInterface وExperience وServices وHyprland وNiri وKeybinds وProfile وAbout، بالإضافة إلى البحث والتنقل ومكوّنات الأقسام وبدء التطبيقات. Hyprland وNiri بديلان حسب الجلسة، وKeybinds يظهر حاليًا مع Hyprland؛ Profile يُفتح من رأس القائمة وليس صفحة ضمن مصفوفة التنقل.

| المشكلة في الوضع الحالي | الدليل من الواجهة الحالية | القرار |
|---|---|---|
| المظهر موزع بين صفحات متعددة | Quick: الشفافية والملف الجاهز؛ Interface: المؤثرات والألوان والخطوط؛ Experience: الثيمات؛ Hyprland/Niri: زخرفة النوافذ | واجهة موحدة للمظهر، وتفاصيل المؤثرات في المتقدم |
| إشعارات النظام ضمن إعدادات الشريط | Bar: الموضع والمهلة؛ Experience: الشكل والهدوء وقواعد التطبيقات | جمعها في الإشعارات؛ مؤشر الشريط وحده يبقى مع الشريط |
| مسار التقاط الشاشة مفكك | General: المحرر؛ Services: الجودة والمسارات؛ Interface: تحديد المنطقة | صفحة واحدة لالتقاط الشاشة مع تفاصيلها المتقدمة |
| إعدادات الساعة مرتبطة بعدة أسطح | General: تنسيق الوقت؛ Desktop: شكل الساعة؛ Bar: ساعة الجزيرة | صيغة عامة للوقت، وتصميم محلي لكل ساعة، مع خيار اتباع الصيغة العامة |
| شاشة القفل مدفونة في Interface | الظهور والحماية والبصمة والمواضع والتمويه في صفحة طويلة | صفحة أساسية للقفل والطاقة، وصفحة متقدمة للتفاصيل |
| إعدادات الاستخدام اليومي تختلط بالمحررات | لغة لوحة المفاتيح بجوار XKB؛ شكل الحركة بجوار منحنيات spring؛ عرض الشريط بجوار ميلي ثانية وبكسلات | نقل كل خيار بحسب طبيعة استخدامه، وليس بحسب الملف الذي يخزنه |
| تكرار مباشر لبعض الخصائص | معاينة مساحات العمل في Bar وInterface؛ فترة تغيير الخلفية في Desktop وInterface؛ عتامة النوافذ في Experience وHyprland | محرر واحد للخاصية وروابط إليه |
| أسماء عامة لا تحدد الغرض | General وInterface وExperience وServices | إلغاء هذه العناوين من التنقل الجديد، وتوزيع مجموعاتها حسب الموضوع |

## 2. شجرة القوائم المقترحة

```text
الإعدادات
├─ البحث في جميع الإعدادات
├─ التخصيص العادي
│  ├─ المظهر والخلفيات
│  ├─ سطح المكتب والويدجتس
│  ├─ الشريط واللوحات
│  ├─ القفل والطاقة
│  ├─ الإشعارات والصوت
│  ├─ الشاشات والنوافذ والإدخال
│  ├─ التطبيقات والبحث
│  ├─ التقاط الشاشة
│  └─ اللغة والوقت والملف الشخصي
├─ ▸ متقدم
│  ├─ الألوان والمؤثرات والحركة
│  ├─ تفاصيل الويدجتس
│  ├─ تفاصيل الشريط واللوحات
│  ├─ تفاصيل القفل والطاقة
│  ├─ قواعد الإشعارات والصوت
│  ├─ الشاشات وإدارة النوافذ
│  ├─ الإدخال والاختصارات
│  ├─ البحث والتكاملات
│  ├─ جودة الالتقاط والمحرر
│  └─ النظام وملفات التهيئة
└─ حول النظام والتحديثات
```

صفحة البداية هي «المظهر والخلفيات». يمكن الاحتفاظ بصفحة «نظرة سريعة» لاحقًا كروابط أو إعدادات مثبتة من المستخدم، لكن لا تُعاد صناعة نسخة أخرى من الخيارات الحالية تحت اسم Quick.

## 3. ما يظهر في التخصيص العادي

| الصفحة | المجموعات والخيارات التي تظهر مباشرة |
|---|---|
| **المظهر والخلفيات** | الثيم الجاهز، فاتح/داكن، اللون الأساسي التلقائي أو المختار، خلفية الديسكتوب والقفل وربطهما اختياريًا، صورة أو فيديو، مجلد الخلفيات، التبديل التلقائي، مؤثر الألواح: معتم/شفاف/تمويه/زجاج بحسب الدعم، نمط الحركة الجاهز، ملف الأداء، الخط العام، ثيم الأيقونات والمؤشر وحجمه |
| **سطح المكتب والويدجتس** | كتالوج واحد للويدجتس: ساعة، طقس، تقويم، ساعة عالمية، ملاحظات، مهام، مؤقتات، بطاقة المستخدم، وسائط، صور، صورة مخصصة، موارد، شبكة، سجل النظام، مدة التشغيل، وأنواع المؤثر الصوتي الثلاثة؛ اختيار مستقل «الديسكتوب / شاشة القفل»؛ زر تخصيص كل سطح؛ اختيار الشاشات الفعلية المستهدفة وفق الإمكانات الحالية؛ شكل الساعة للديسكتوب والقفل، اتجاهها وتاريخها ولونها وحجمها، النص المقتبس، الصورة المخصصة، شبكة المحاذاة وخطوط الالتقاط |
| **الشريط واللوحات** | نوع الشريط، موضعه، ترتيب عناصره، أسلوبه الجاهز، الإخفاء التلقائي، الشاشات التي يظهر عليها؛ الدوك وإظهاره وتثبيته وأزراره؛ عناصر اللوحتين الجانبيتين؛ ترتيب التبديلات السريعة ومنزلقات الصوت والإضاءة؛ محتوى مساحات العمل؛ عرض المشغل ومراقبة الموارد؛ أزرار الأدوات؛ شكل ساعة الجزيرة وتاريخها وثوانيها؛ إظهار Pomodoro وسلوك الضغط عليه |
| **القفل والطاقة** | فتح تخصيص القفل، ظهور عناصر التحكم والوسائط، إخفاؤها عند الخمول، القفل عند بدء الجلسة، توسيط الساعة؛ خيارات المصادقة المتاحة والبصمة والوجه؛ طلب كلمة المرور عند إيقاف التشغيل؛ شكل قائمة الجلسة وموقعها والإجراءات الظاهرة وتأكيد الإيقاف؛ الإيقاف المؤقت التلقائي عند انخفاض البطارية؛ روابط لخلفية القفل والويدجتس في أماكنها الأساسية |
| **الإشعارات والصوت** | نمط الإشعارات وموضعها وشكلها، التوقف أثناء تمرير المؤشر، التوسيع عند المرور، إسكات النوافذ المنبثقة أثناء مشاركة الشاشة، السماح بالتنبيهات الحرجة؛ أصوات البطارية وPomodoro؛ حماية ارتفاع الصوت وحد الصوت الأقصى |
| **الشاشات والنوافذ والإدخال** | ترتيب الشاشات بالسحب، الدقة والتردد والتكبير والاتجاه والتفعيل؛ نوع ترتيب النوافذ والمسافات العامة؛ توحيد مساحات العمل بين الشاشات؛ لغات لوحة المفاتيح واختصار تبديلها وNumlock؛ سرعة المؤشر والتمرير الطبيعي والنقر على لوحة اللمس وتعطيلها أثناء الكتابة؛ زوايا الشاشة وأفعالها؛ تعديل الاختصارات القائمة بالتقاط الأزرار حيث يدعمه المحرر الحالي |
| **التطبيقات والبحث** | المشغل الافتراضي، التطبيقات الافتراضية حسب نوع الملف عبر اختيار تطبيق، البحث عن الملفات، مصادر نتائج البحث، الظهور في نتائج البحث العادية؛ برامج بدء التشغيل المدعومة؛ سياسة الذكاء الاصطناعي وتشغيل الترجمة؛ مدينة الطقس والموقع والوحدة؛ تفضيلات المحتوى والخصوصية التي كانت تحت Work safety وWeeb |
| **التقاط الشاشة** | مكان حفظ الصور والفيديو، ماذا يحدث بعد الالتقاط، فتح المحرر أو النسخ، الحفظ مع النسخ، الإغلاق بعد الحفظ أو النسخ، التأكيد عند وجود تعديلات، تسجيل الصوت: النظام/الميكروفون/كلاهما/بدون؛ اختيار جودة عامة يستند إلى قيم التسجيل الحالية، أدوات تحديد المنطقة المعتادة |
| **اللغة والوقت والملف الشخصي** | لغة الواجهة، 12/24 ساعة، إظهار التاريخ والثواني، الصورة الشخصية والاسم والوصف؛ حفظ واستعادة الإعدادات الجاهزة الموجودة في Profile. رابط إلى معلومات اسم الجهاز تحت حول النظام |

القاعدة: الخيار المرئي المتكرر أو الاختيار المفهوم مباشرة يبقى عاديًا حتى لو كان مصدره حاليًا صفحة Hyprland. الرقم الدقيق أو صيغة الأمر أو الاستثناء أو تفاصيل محرك المؤثر يذهب إلى المتقدم. بعض أدوات الاختيار المبسطة أعلاه، مثل اختيار التطبيق بدل كتابة اسم ملفه، تحسينات مقترحة أثناء التنفيذ وليست وصفًا لواجهة موجودة بالفعل.

## 4. كل الإعدادات المتقدمة، بما فيها التفاصيل شديدة التخصص

| الفرع | المحتوى المنقول إليه |
|---|---|
| **الألوان والمؤثرات والحركة** | نوع لوحة الألوان، كود اللون، الشفافية التلقائية ونسب الخلفية والمحتوى، عتامة الزجاج، تلوين الخلفية، تدوير حواف الشاشة؛ نسب عتامة النوافذ النشطة وغير النشطة وملء الشاشة، التعتيم، الحدود وألوانها وألوان الثيم التلقائية، تفاصيل الظلال؛ كل معاملات Blur: الحجم والتمريرات والحيوية والضجيج والتباين والسطوع وXRay والنوافذ المنبثقة؛ كل أنماط Glass/Acrylic/Ripple/Drops/Water/Fluid Jar/Heat Shimmer/Aurora/Haze ومعاملاتها؛ سرعة الحركة والتفاف المساحات، منحنيات Bezier/Spring وشجرة الحركة والوراثة؛ الخطوط المتخصصة للأرقام والعناوين والكود والقراءة والأيقونات؛ توليد ألوان Qt والطرفية والتناغم والسطوع |
| **تفاصيل الويدجتس** | استراتيجية التموضع الآلي؛ وزن وعرض واستدارة خط الساعة، المحاذاة التكيفية وحركة الأرقام؛ إعدادات Cookie كاملة: الذكاء الاصطناعي، التطبيق القديم، الأضلاع، الدوران، العلامات، العقارب، الأرقام والتاريخ؛ إعدادات شكل الصورة والخلفية المركزية وحجمها ولونها وظهورها في القفل؛ عرض وارتفاع ونطاقات المؤثر الصوتي والضجيج والاستجابة والتنعيم والمسافات، الإيقاف أثناء تغطية الديسكتوب؛ تمويه الخلفية الجزئي ونسبته وجهته وانتقالات الخلفيات الدقيقة |
| **تفاصيل الشريط واللوحات** | تخصيص كل وضع للشريط في مكانه: Classic/Mesobar/M3 Island والأوضاع الأخرى الحالية؛ عرض الشريط بالنسبة أو البكسل، الإطار وسمكه ولونه والزوايا ومجموعات الألوان؛ ارتفاع توسع الجزيرة وسرعتها والتحام المشغل والنتائج والتمرير وحجز مساحة الشاشة وقناع وضوح خلفيتها؛ مجال الإظهار بالمرور ودفع النوافذ والإظهار عند Super؛ عرض زر المهمة والوسائط والفاصل؛ عتبات مراقبة الموارد وفترة التحديث؛ تخصيص Tray والتلميحات؛ أعمدة التبديلات السريعة، تخطيط Overview وصفوفه وأعمدته واتجاه الترتيب وتأخر التمركز؛ إبقاء اللوحة اليمنى محملة؛ موضع واجهة اختيار الخلفية وأعمدتها وسلوك البحث والإغلاق؛ حدود وشكل نافذة الإعدادات |
| **تفاصيل القفل والطاقة** | اختيار Hyprlock أو Quickshell، تخطيط مستقل لكل شاشة فعلية، الشاشة الرئيسية وصندوق الفتح عليها فقط؛ موضع صندوق كلمة المرور والهوامش وإزاحة وحجم كل عنصر؛ شكل محارف كلمة المرور والنص؛ عينات التمويه وتكبير الخلفية؛ بدء فحص البصمة أو الوجه تلقائيًا وحركة المستشعر ومهلة الوجه وأمر المصادقة وفك keyring؛ عرض ورقة الجلسة وعدد أعمدتها وتفاصيلها؛ حدود البطارية المنخفضة والحرجة والممتلئة ونسبة التعليق التلقائي |
| **قواعد الإشعارات والصوت** | المهلة العامة، الحد الأقصى للبطاقات، تأخر التوسيع، مدة الجزيرة كاستثناء من المهلة العامة، معاينة آخر الإشعارات وعددها؛ محرر قواعد كل تطبيق مع الإبقاء على تحرير JSON؛ مقدار قفزة الصوت المسموحة ومهلة مؤشر الصوت والإضاءة (OSD). مؤشر العدد على الشريط يُضبط من الشريط لأنه يتحكم في عنصر الشريط نفسه |
| **الشاشات وإدارة النوافذ** | إحداثيات الشاشات اليدوية، المرآة وBit depth وVRR وإدارة اللون والمنطقة المحجوزة والتحويلات؛ إعدادات Dwindle/Master/Group أو أعمدة Niri؛ الالتقاط ومسافات الالتقاط والحدود والمساحات العائمة؛ قواعد النوافذ ومساحات العمل والقواعد المخصصة وخصائص الطبقات؛ خيارات التركيز الدقيقة وDPMS وAllow tearing وشعار Hyprland وشاشة البدء؛ تخصيصات Niri المميزة مثل حلقة التركيز. يحتفظ كل محرك بإمكاناته الفعلية |
| **الإدخال والاختصارات** | XKB options/variant/model/rules، معدل تكرار المفاتيح وتأخيره؛ ملفات التسارع وأزرار التمرير واليد اليسرى وtap mapping وdrag lock؛ تكبير المؤشر وإخفاؤه والمهلة وwarps؛ مسافة إيماءات المساحات وسرعتها والإلغاء وقفل الاتجاه؛ إنشاء اختصار مخصص وDispatcher/Params والوصف والتعارضات؛ تحرير Lua للاختصارات وإعادة تحميلها وإعادة ضبطها. الالتقاط المبسط لا يُعرض على Niri كأنه مدعوم حاليًا |
| **البحث والتكاملات** | خوارزمية المطابقة، كل بادئات البحث الأحد عشر، الحد الأدنى لحروف الملفات وعدد النتائج؛ أوامر فتح الملفات، SSH وخدمات systemd والنطاق العام؛ رابط محرك البحث؛ أسماء ملفات desktop الخام للتطبيقات الافتراضية؛ AI system prompt وHTTP user agent؛ مهلة التعرف على الموسيقى وفترة الاستعلام، تحديث الطقس؛ بيانات hotspot الموجودة حاليًا في Quick Actions |
| **جودة الالتقاط والمحرر** | نسبة صورة الالتقاط وصيغتها وجودة JPEG؛ FPS وCodec والجودة ومصادر الصوت اليدوية؛ تشغيل الفيديو وتكراره وكتمه افتراضيًا؛ مدة التعليق وأداة الرسم ولونها وسُمكها وتعتيم المحرر ومسح التعليقات والإغلاق بـEsc أو النقر بالخارج؛ تفاصيل دوائر التحديد والحشو والخطوط واقتراح النوافذ والطبقات والمحتوى وGoogle Lens؛ Overlay والصورة العائمة وكود علامة التصويب ومحررها ومهلة مؤشر فتح التطبيقات وطبقته وحركة التكبير |
| **النظام وملفات التهيئة** | توليد locale بدل تغيير لغة الواجهة البسيط، وصيغ الوقت والتاريخ الخام؛ تغيير اسم الجهاز بإجراء التأكيد والمصادقة الحالي؛ ملفات include وإصلاح ترتيبها في Niri، ومعلومات ملفات Hyprland وفتحها أو إعادة تحميلها؛ تفاصيل بدء التطبيقات: الأمر والتأخير ومساحة العمل؛ فترة فحص التحديثات. محررات قواعد النوافذ والاختصارات والحركة تبقى في فروعها المتخصصة ويُوضع هنا رابط إليها فقط |

| المصدر الحالي | وجهته في المخطط |

| Quick | المظهر والخلفيات + الشريط واللوحات؛ تُلغى النسخ المكررة |
| General / Time وLanguage | اللغة والوقت؛ صيغ التنسيق الخام وتوليد locale في المتقدم |
| General / Screen Canvas | التقاط الشاشة + جودة الالتقاط والمحرر |
| General / Battery | القفل والطاقة؛ العتبات في المتقدم |
| General / Audio وSounds | الإشعارات والصوت |
| General / Work safety | التطبيقات والبحث / الخصوصية والمحتوى |
| Desktop / Wallpaper | المظهر والخلفيات؛ التفاصيل الرقمية في تفاصيل الويدجتس |
| Desktop / Clock وQuote وCustom Image وWidgets وCanvas | سطح المكتب والويدجتس؛ التفاصيل الفنية في تفاصيل الويدجتس |
| Bar / Mode وScreens وLayouts وPositioning | الشريط واللوحات؛ تخصيص المقاسات والتوقيتات في تفاصيله |
| Bar / M3 وMesobar وTasklist وSystem Monitor وQuick Actions وInfo Strip | تحت نوع الشريط المختار؛ الأساسية في العادي والدقيقة في المتقدم |

## 6. سلوك سهم «متقدم»

1. مغلق عند أول استخدام، وله اسم واضح وسهم واتجاه صحيح بالعربية؛ قابل للتشغيل بالفأرة ولوحة المفاتيح.
2. الضغط يفتح فروع المتقدم كلها في القائمة نفسها. لا يُحمّل كل محتواها ولا يفرد آلاف الأسطر في صفحة واحدة.
3. تظهر الفروع العشرة كاملة؛ لكل فرع مجموعات قصيرة بعناوين مفهومة. المحررات شديدة التخصص موجودة داخله ولا تحتاج تفعيل «وضع خبير» آخر.
4. طي المجموعة يخفي قائمة الفروع فقط، ولا يغيّر قيم الإعدادات ولا يمسح مسودة المحرر المفتوح. تظل الصفحة المفتوحة وعنوان مسارها واضحين.
5. تتذكر الواجهة حالة الفتح والصفحة الأخيرة. العرض المصغر الحالي للإعدادات يبقى اختيارًا بصريًا؛ لا يُستخدم كمرادف للعادي أو المتقدم.
6. آخر كل صفحة عادية رابط «تفاصيل متقدمة لهذا القسم» يفتح الفرع الصحيح، دون نسخ حقوله إلى الصفحة العادية.
7. الخيارات المشروطة تظهر حسب نوع الشريط والمحرك والقدرات الفعلية. اختيار مؤثر يعرض معاملاته فقط؛ بقية الأنماط تظل متاحة من الاختيار نفسه.

## 7. البحث والتسميات

البحث يشمل العادي والمتقدم حتى والسهم مغلق. كل نتيجة تعرض اسم الخيار ومساره وشارة «متقدم» عند الحاجة؛ الضغط عليها يفتح الفرع والمجموعة ثم يمرر إلى **الخيار نفسه** ويبرزه. لا يكتفي بالوصول إلى عنوان قسم واسع كما يفعل التنقل الحالي.

تُعطى الصفحات والمجموعات والخيارات معرفات ثابتة مستقلة عن الترجمة. يحتفظ النظام بأسماء الأقسام الإنجليزية القديمة ومرادفات عربية مثل «قفل/لوك سكرين» و«شريط/بار» و«خلفية/والبيبر» للبحث وروابط التوافق. لا تُستخدم الترجمة كمفتاح للتنقل؛ الأسلوب الحالي `pageName:sectionTitle` يحتاج طبقة توافق للروابط القديمة.

تُستبدل العناوين المبهمة مثل Enable وStyle وDefault Settings بأسماء تخص الميزة عندما يكون السياق غير ظاهر. تُعرض وحدات مفهومة: ثوانٍ للمستخدم المعتاد، بينما تبقى القيم الأصلية الدقيقة في المحرر المتقدم. لا يتم تغيير معنى الخاصية المخزنة لمجرد تبسيط اسمها.

## 8. خطة البناء التقنية

**المرحلة الأولى — توثيق التغطية والملكية:** تحويل هذا الجرد إلى سجل ثابت لكل خيار: `id`، الاسم، الموضوع، `basic/advanced`، خصائص التخزين، المحرك المدعوم، شرط الظهور، مالك الكتابة، الإجراء الجانبي، الكلمات المفتاحية، ومسار الوصول القديم. لا يعتمد الفهرس النهائي على استخراج النصوص آليًا من الواجهة.

**المرحلة الثانية — فصل السلوك عن الصفحات:** توجد كتابة إلى Hyprland عند `Component.onCompleted`، كما يفعّل `SettingsContent` تحميل الصفحات كلها مبكرًا. قبل التحميل عند الطلب، يُنقل تزامن إعدادات المحرك إلى خدمة ذات مسؤولية واضحة. فتح صفحة أو توسيع السهم لا يطبق ثيمًا أو يعيد كتابة إعدادات النظام. يُراجع كذلك كل `onCheckedChanged/onValueChanged` لتجنب الكتابة الناتجة عن التهيئة وحدها.

**المرحلة الثالثة — التنقل والسهم والبحث:** إنشاء نموذج التنقل والسجل أولًا، وربط الصفحات الحالية به مؤقتًا. بناء الفهرس من السجل ليعمل قبل تحميل صفحات المتقدم؛ انتظار تحميل الوجهة قبل فتح المجموعة والتمرير للخيار. حفظ حالة العرض منفصلًا عن تفضيلات النظام.

**المرحلة الرابعة — استخراج المجموعات وتوحيد المتكرر:** تقسيم الصفحات الكبيرة إلى مكونات حسب الميزة. يبدأ العمل بالمظهر، والويدجتس والقفل، والإشعارات، والالتقاط لأنها أوضح مواضع التشتت؛ بعدها الشريط والإدخال والتكاملات. استخدام المحرر نفسه في الإعدادات ووضع التخصيص لتفادي اختلاف السلوك.

**المرحلة الخامسة — إكمال المتقدم والتوافق:** نقل جميع تفاصيل Hyprland وNiri والمحررات الخام دون إسقاطها؛ ربط واجهة موحدة بخدمة المحرك الصحيح، لا نسخ قيم Hyprland إلى Niri. الحفاظ على مفاتيح Config الحالية في هذه الجولة، وفصل أي ترحيل لاحق عن إعادة ترتيب القوائم.

**المرحلة السادسة — الاختبار والتنقيح:** فحص التغطية والبحث وروابط التنقل والتحميل والكتابة والحفظ والإلغاء، ثم مراجعة واجهة فعلية بالعربية والإنجليزية وبالعرضين العادي والمصغر.

مكونات مقترحة: `SettingsRegistry` للهوية والفهرسة؛ `SettingsNavigation` للعادي وسهم المتقدم؛ `SettingsPage` لعرض الموضوع؛ مجموعات مستقلة مثل `WidgetVisibilitySettings` و`NotificationSettings` و`CaptureSettings`؛ موصلات قدرات للمحركات الحالية. هذه أسماء التصميم الأصلي؛ التنفيذ الحالي يستخدم SettingsRegistry وSettingsNavigationButton وSettingsContent مع إعادة استخدام صفحات المصدر لحفظ حالة المحررات.

## 9. شروط قبول التنفيذ

- لكل خيار حالي وجهة موثقة؛ لا تُسقط الخيارات التقنية بحجة التبسيط.
- لا يوجد محرران مختلفان يكتبان الخاصية نفسها بسلوك مختلف. يمكن عرض رابط أو نفس المكون في سياق آخر.
- تغييرات المظهر الجاهزة تبيّن نطاق تأثيرها، وملف الأداء يوضّح إن كان سيغيّر ويدجتس أو مؤثرات؛ لا يحدث تفعيل أو نقل ويدجتس ضمنيًا بسبب إعادة التنظيم.
- اختيار ظهور ويدجت على القفل لا يشترط تفعيله على الديسكتوب، وموقعه على أحدهما لا يغيّر الآخر. تطابق الاختيارات بين الإعدادات ومحرر التخصيص.
- فتح المتقدم أو البحث أو تغيير اللغة لا يكتب ملفات المحرك ولا يغير القيم ولا يمسح مسودات Lua/JSON.
- كل خيارات المتقدم قابلة للبحث عندما تكون المجموعة مغلقة والصفحات غير محملة.
- روابط `GlobalStates.settingsPage` القديمة تستمر في الوصول للموضع المناظر، بما فيها الصفحات ذات الأسماء المترجمة.
- وظائف Hyprland وNiri تعرض الدعم الحقيقي، ولا تُوعد الجلسة بوظيفة محرر غير موجودة.
- الحقول التي تحتاج تطبيقًا أو حفظًا صريحًا تحافظ عليه؛ الخيارات الفورية تظل فورية. لا يُضاف زر حفظ عام يوهم بأن جميع الإعدادات مؤجلة.
- مراجعة التمرير والتركيز وحالة السهم والوحدات والنصوص الطويلة وRTL وعدم بتر التسميات في النافذة المصغرة.

أُنجز تنفيذ تنظيم الواجهة بعد اعتماد المخطط؛ الجرد أدناه مرجع للنسخة الأصلية، وقد تغيّرت مواضع الخيارات وأسماء الأقسام في التنفيذ.


## حالة التنفيذ

تم تطبيق تسعة أقسام يومية وعشرة أقسام متقدمة تحت سهم واحد، مع أسماء مختصرة ورأس للنافذة وزر إغلاق. البحث يشمل الأقسام المغلقة ويفتح مكان الخيار، والروابط القديمة ما زالت تُوجّه إلى مواضعها الجديدة. أُزيلت محررات الخصائص المكررة، ونُقلت التفاصيل إلى أقسامها، وأصبح حفظ المحررات التقنية صريحًا. لا يغيّر تصفح الأقسام قيم الإعدادات. يدعم التنقل اتجاه العربية، مع ترجمة أسماء الأقسام الجديدة؛ ترجمة كل الخيارات القديمة ليست مكتملة.

تمت تجربة تحميل المسارات العشرين داخل Quickshell، وفحص صور صفحات الالتقاط والويدجتس والواجهة العربية.
